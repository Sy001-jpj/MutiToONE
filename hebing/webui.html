MutiToONE 使用说明

这个工具做什么

把「一年一个文件、题目与答案分开存放」的真题 PDF，自动合成一本 题目 1 → 答案 1 → 解析 1 → 题目 2 → … 的合订本（Word / PDF / Markdown）。 它按题号把两份 PDF 切开再重新对齐，图形题会保留原图，资料分析的公共材料会挂在所属题组前面。

不限于公务员考试 —— 只要题目和答案分在两份文件里，且题目按题号连续编号，各类考试都能用； 项目里自带的那批是江苏省考行测（A 类），只是用作示例。

怎么用

  1. 把真题 PDF 放进任意一个文件夹（不用改名、不用建子目录，平铺就行）
  2. 在顶部目录框填入或点 浏览… 选中该文件夹
  3. 点 扫描 —— 列出「哪一年 / 哪份题目 / 哪份答案」，逐行显示配对状态
  4. 选年份区间，点 生成合订本，先选存放位置，进度条走完后点下载

能识别什么、不能识别什么

只能处理带文字层的 PDF（非扫描件）。程序靠读取 PDF 里的文字来判断题号、选项和答案解析的位置， 如果 PDF 是扫描出来的图片（整页只有图像、没有可复制的文字），就读不到题号，这类文件无法解析。

  • 可用：从考试机构官网、题库下载的正规 PDF；用 Word/WPS 导出的 PDF；有文字层的电子版
  • 不可用：手机拍照转的 PDF、扫描仪扫的 PDF、整页截图的 PDF

判断方法：用浏览器或阅读器打开，能选中并复制文字的就是可用的；拖选一片全是蓝框、复制不出字的，就是扫描件。

补充：如果只有答案是扫描件，程序仍会照常生成合订本，只是把那份扫描版答案以整页图片的形式附在书末 （项目里的 2017 年就是这种情况）。

扫描件需要 OCR 识别，本程序没有内置 OCR。若有需要，可先用外部工具把扫描件转成带文字层的 PDF 再交给本程序。

成品叫什么、存在哪

成品统一命名为 合订本.docx（勾选导出 PDF 时另有 合订本.pdf）， 存放位置在点「生成合订本」时由你选择，默认定位在真题所在的文件夹。同名文件会被覆盖。

左下角 设置 → 退出 关闭程序。

LinkSwift 是什么

LinkSwift（网盘直链下载助手）是一个开源的浏览器油猴脚本，能在网盘页面直接给出文件的真实下载地址， 省掉「装客户端 + 一个个点」的麻烦，支持百度网盘、夸克、阿里、123 等多家网盘。

它不是本程序的一部分：本程序不随包分发它，只在你要的时候从官方仓库取最新版。

组件里能做什么

点左侧 组件 打开的窗口里，可以：

  • 检查 LinkSwift 更新 —— 对比官方仓库的最新版本，发现新版可一键下载并安装到浏览器
  • 检查 MutiToONE 自身更新 —— 对比 GitHub 上发布的最新版本；检测到新版本时会自动更新， 更新完成后重启程序即可生效

若「检查更新」提示未配置更新源，说明当前这份程序还没有绑定 GitHub 仓库。
